\# Student Performance Prediction – Final AI \& ML Project



\## 📌 Project Overview



This is my final AI \& Machine Learning project. The project uses Python and Scikit-learn to build a Machine Learning model that predicts student performance based on study habits, attendance, previous scores, assignment completion, sleep, and participation.



The dataset used in this project is simulated for educational purposes.



\## 🎯 Project Objective



The main objective is to demonstrate a complete Machine Learning workflow:



\- Data creation

\- Data exploration

\- Data cleaning

\- Data visualization

\- Feature preparation

\- Train/test split

\- Model training

\- Model comparison

\- Model evaluation

\- Feature importance

\- Prediction on new data



\## 🛠️ Technologies Used



\- Python

\- NumPy

\- Pandas

\- Matplotlib

\- Scikit-learn

\- Google Colab



\## 🤖 Machine Learning Models



Two classification models were trained and compared:



1\. Logistic Regression

2\. Random Forest Classifier



The models were evaluated using:



\- Accuracy

\- Precision

\- Recall

\- F1 Score

\- Confusion Matrix



\## 📊 Features Used



The model uses the following features:



\- Study Hours Per Day

\- Attendance Percentage

\- Previous Score

\- Assignment Completion Percentage

\- Sleep Hours

\- Participation Score
